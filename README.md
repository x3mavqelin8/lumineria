# アイカツ！アンコール

アイカツ！アンコールのカードを管理・検索するための個人用Webアプリです。

カードの所持状況やカード詳細を管理できるほか、カード検索、コーデ表示、パラレルカードの管理、取扱店舗の検索・地図表示などに対応しています。

## 主な機能

### 簡単更新方法

- `node tools/downloadImages.js`
  → カード画像だけをダウンロード

- `node tools/importExcel.js`
  → Excelのカードデータだけを `cards.json` に反映

- `node tools/update.js`
  → `importExcel.js` と `downloadImages.js` をまとめて実行

- `node tools/geocodeShops.js`
  → `shoplist.json` に登録されている店舗の住所から、座標だけを取得・更新

- `node tools/updateShops.js`
  → dataフォルダの中にあるshoplist.pdfを読み取り
  `shoplist.json` に追加・削除・変更、座標を自動取得

### カード管理

- カード一覧表示
- カード番号・カード名での検索
- レアリティ・タイプ・カテゴリ・ブランドなどによる絞り込み
- 所持枚数の記録
- 所持カード・未所持カードの絞り込み
- パラレルカードのみの絞り込み
- 検索条件のリセット
- カード詳細の表示・編集
- カード表示／コーデ表示の切り替え
- 通常カードとパラレルカードの管理

### パラレルカード

パラレルカードは通常カードと区別して管理します。

Excelでは、パラレルカードのカード番号に `★` を付けます。

```text
E1-01
E1-01★
```

画像ファイルは通常カードと区別するため、パラレルカードには `_p1` が付きます。

```text
通常：
E1-01_PR.webp
E1-01_PR_b.webp

パラレル：
E1-01_PR_p1.webp
E1-01_PR_p1_b.webp
```

コーデ表示で通常カードとパラレルカードを分けるため、Excelの `coordinateName` は通常カードとパラレルカードで別の名前にします。

### 取扱店舗

- アイカツ！アンコール取扱店舗の一覧表示
- 店舗検索
- お気に入り店舗
- 現在地を基準にした店舗検索
- 距離範囲の指定
- 地図表示
- 店舗の位置情報表示
- 店舗情報の表示

2026年10月8日時点の店舗データは1,378店舗です。

## JavaScriptファイルの役割

### `js/app.js`

アプリ全体の初期化や画面の基本処理を担当します。

### `js/cards.js`

カード一覧、検索、フィルター、所持状況、カード／コーデ表示などを担当します。

### `js/modal.js`

カード詳細モーダルの表示・編集・保存を担当します。

### `js/shop.js`

取扱店舗の検索・表示、店舗情報、地図表示などを担当します。

### `js/storage.js`

ブラウザ内へのデータ保存・読み込みを担当します。

## カードデータ

カードの基本情報は `data/cards.json` で管理します。

元データは `data/carddata.xlsx` です。

カード画像は `images/` に配置します。

### 通常カード

```text
E1-01_PR.webp
E1-01_PR_b.webp
```

### パラレルカード

```text
E1-01_PR_p1.webp
E1-01_PR_p1_b.webp
```

`_b` はカード裏面の画像です。

## カードデータ・画像の更新

カード情報を更新するときは、プロジェクトのルートフォルダで次のコマンドを実行します。

```bash
npm run update
```

`update.js` が次の処理をまとめて実行します。

1. `tools/importExcel.js`
   - `data/carddata.xlsx` からカード情報を読み込みます。
   - `data/cards.json` を更新します。
   - 新規カードや変更されたカードを反映します。

2. `tools/downloadImages.js`
   - 不足しているカード画像をダウンロードします。
   - すでに存在する画像は再ダウンロードしません。

直接実行する場合は、次のコマンドでも同じ処理を行えます。

```bash
node tools/update.js
```

### パラレルカードを追加・変更するとき

Excelのカード番号に `★` を付けます。

```text
E1-01★
```

画像は `_p1` のファイル名で管理されます。

また、コーデ表示で通常カードとパラレルカードを分ける場合は、Excelの `coordinateName` も通常カードとパラレルカードで分けます。

## 店舗データ・座標の更新

店舗の座標を更新するときは、

```bash
npm run geocode
```

を使用します。

これは `tools/geocodeShops.js` を実行します。

直接実行する場合：

```bash
node tools/geocodeShops.js
```

店舗データは `data/shoplist.json` で管理します。

## package.json のスクリプト

現在使用するコマンドは次の2つです。

```bash
npm run update
npm run geocode
```

- `update`：カードデータ・カード画像を更新
- `geocode`：店舗の座標を更新

## 保存データ

カードの所持枚数やカード詳細の編集内容など、ブラウザ側で変更したデータは `localStorage` に保存されます。

ブラウザのサイトデータを削除すると、保存していたデータが消える可能性があります。

## 開発メモ

- JavaScriptはES Modulesを使用しています。
- ローカルサーバー経由で起動してください。
- カードデータを更新するときは `npm run update` を使用します。
- 店舗座標を更新するときは `npm run geocode` を使用します。
- `node_modules/` は通常Git管理の対象に含めません。
- カードデータを変更する場合は、`cards.json` を参照している画面との整合性を確認してください。
