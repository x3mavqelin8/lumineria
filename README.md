# アイカツ！アンコール カード管理アプリ

アイカツ！アンコールのカードを管理するための個人用Webアプリです。

カードの一覧表示や検索、所持枚数の記録、カード詳細の編集などを行えます。

## 主な機能

- カード一覧の表示
- カード番号・カード名での検索
- レアリティ、タイプ、カテゴリ、ブランドによる絞り込み
- 所持チェックと所持枚数の記録
- 所持状況の集計とコンプリート率の表示
- カード詳細の編集
- 編集したカード詳細・所持枚数のブラウザ内保存

## 使用技術

- HTML
- CSS
- JavaScript（ES Modules）
- JSON
- Node.js
- npm
- xlsx
- `localStorage` によるブラウザ内データ保存

## 起動方法

このアプリは、ローカルサーバー経由で起動します。

1. プロジェクトフォルダをVisual Studio Codeで開きます。
2. Live Serverなどのローカルサーバーを使用して、`index.html` を起動します。
3. ブラウザで表示されたページを開きます。

`index.html` を直接ブラウザで開くのではなく、ローカルサーバー経由で使用してください。

## JavaScriptファイルの役割

### `js/app.js`

アプリ全体の初期化を担当します。

- `data/cards.json` の読み込み
- 保存済みのカード詳細・所持枚数の反映
- ブランド絞り込みの選択肢作成
- カード一覧・モーダルの初期化と連携

### `js/cards.js`

カード一覧画面を担当します。

- カード一覧の描画
- 検索・フィルター
- 所持チェックと所持枚数の操作
- 所持状況の集計表示

### `js/modal.js`

カード詳細モーダルを担当します。

- カード詳細の表示・編集
- 編集内容の保存
- モーダルの開閉

### `js/storage.js`

ブラウザ内へのデータ保存・読み込みを担当します。

- 所持枚数の保存・読み込み
- カード詳細の保存・読み込み

## カードデータ

カードの基本情報は `data/cards.json` で管理します。

カード画像は、プロジェクト直下の `images/` に配置します。

カード画像のファイル名は、カード番号とレアリティコードを組み合わせた形式です。

例：

```text
E1-01_PR.webp
E1-01_PR_b.webp
```

`_b` が付いている画像はカードの裏面です。

カード詳細の編集内容や所持枚数は、基本データとは別にブラウザの `localStorage` に保存されます。

## カードデータ・画像の更新

カード情報は `data/carddata.xlsx` をもとに管理しています。

Excelの内容を反映し、不足しているカード画像をダウンロードする場合は、プロジェクトのルートフォルダで次のコマンドを実行します。

```bash
node tools/update.js
```

このコマンドでは、次の処理を順番に実行します。

1. `tools/importExcel.js`
   - Excelからカード情報を更新・新規登録します。

2. `tools/downloadImages.js`
   - 不足しているカード画像をダウンロードします。

既存の画像は再ダウンロードせず、不足している画像のみを取得します。

## 保存データについて

このアプリでは、次の `localStorage` キーを使用します。

| キー                     | 保存内容             |
| ------------------------ | -------------------- |
| `aikatsu-encore-owned`   | 所持枚数             |
| `aikatsu-encore-details` | カード詳細の編集内容 |

ブラウザのサイトデータを削除すると、これらの保存内容も消える可能性があります。

必要に応じて、サイトデータを削除する前に保存内容をバックアップしてください。

## 開発メモ

- JavaScriptはES Modulesを使用しているため、ローカルサーバー経由で起動します。
- カードデータを更新する場合は、`node tools/update.js` を使用します。
- `cards.json` の項目を変更する場合は、一覧表示やモーダル側で参照している項目との整合性を確認してください。
- `package.json` と `package-lock.json` は、パッケージや依存関係の管理に使用します。
- `node_modules/` は通常、Git管理の対象に含めません。
